# MONO® — Future Essentials

A fashion concept store built as a scroll-driven 3D experience: a procedural hoodie rendered with React Three Fiber, GSAP-scrubbed camera and layer deconstruction, and a per-product viewer for rotating/recoloring garments.

Stack: Next.js (App Router) + TypeScript, React Three Fiber/Drei/postprocessing, GSAP + ScrollTrigger, Lenis, Framer Motion, Tailwind.

```bash
npm install
npm run dev    # http://localhost:3000
```
